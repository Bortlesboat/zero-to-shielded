# Zero to Shielded

A beginner's path from no wallet to a first shielded Zcash transaction: wallet setup, backup, address types, getting ZEC, shielding, sending/receiving, and unshielding.

Includes a practice simulator showing what the public blockchain reveals at each step, and an in-browser address checker (prefix + checksum, nothing sent anywhere).

Live: https://bortlesboat.github.io/zero-to-shielded/

Single static `index.html`, no build step, no tracking. MIT licensed.
